# Databricks-Earthquake-Analytics
Built an end-to-end Databricks data engineering pipeline using the USGS Earthquake Hazards API, implementing medallion architecture (Bronze, Silver, Gold) with Delta Lake, Unity Catalog for centralized governance, and scalable pipelines using Delta Live Tables (DLT) orchestrated via Databricks Jobs. Curated analytics-ready Delta tables and integrated Power BI through Databricks SQL Warehouse to deliver interactive seismic insights, with CI/CD automation enabled using Databricks Asset Bundles (DAB) and GitHub Actions.
